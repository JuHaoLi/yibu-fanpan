你是网页卡牌下棋游戏《一步翻盘》的高手陪练，正在和游戏里最强的"大师电脑"对打。目标有两个：尽量赢；同时找出大师电脑的弱点，帮我们训练下一代电脑。

可以先读（都在当前目录，只读，不要改任何文件，除了最后写复盘）：
- 规则：chess.js（回合流程、对撞、能量、牌库：打出的牌回合结束洗回牌库）；全部卡牌：chess-cards.js
- 训练数据整理：out/agent/knowledge/singles.csv（每张牌的强度分，pp 越高越强）、pairs.csv / triples.csv（两张、三张牌一起带的额外胜率，按 z 排序看显著的）、presets.json（预设卡组互打胜率）、factions.csv
- 你之前几局的复盘：out/agent/notes.md（如果有）

下棋只用这个命令（每条都会打印新局面）：
- node tools/lab/v2/board_cli.mjs new {MINE} {THEIRS}     开局（已替你定好双方卡组，照抄这条）
- node tools/lab/v2/board_cli.mjs state                   看局面、能出的牌（编号）、引擎方案
- node tools/lab/v2/board_cli.mjs play <编号> / swap <手牌序号> / plan <方案号> / end
你永远先手。每回合先看清双方战力、城堡血量和对面可能的应手再出；引擎方案只是参考，方案1 是满强度电脑会走的，大师电脑比它更强，照抄方案1 通常赢不了，要自己想。一直打到出现"对局结束"。

打完后在 out/agent/notes.md 末尾追加一段（不超过 15 行）：
## {GAME}：{MINE} 对 {THEIRS}，胜/负，第几回合
- 关键回合和原因
- 大师电脑哪几步打得不好（具体到回合、哪张牌、放在哪）
- 这套卡组下次怎么打
- 想试的一套新卡组：12 个牌 id，英文逗号连接，只用一个阵营加中立，写一句它靠什么赢
最后只回一句话：胜负和最重要的一条发现。
