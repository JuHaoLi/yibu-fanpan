# 一步翻盘

一个网页上的构筑卡牌下棋游戏。4 路 × 5 格的棋盘，双方各有一座城堡，把兵一格一格推进对面的城门。组一副 12 张牌的卡组，和电脑对战。

**现在是试玩阶段。** 打开就能玩，玩完请留一条反馈。

- 试玩和反馈：https://cuiyucheng0104-afk.github.io/yibu-fanpan/
- 直接进游戏：https://cuiyucheng0104-afk.github.io/yibu-fanpan/play/

## 有什么

- 六个阵营加中立，366 张牌，各有自己的玩法（圣盾、连击、方尖碑、暗影、成长、冻结……）。
- 自由对战：12 套预设卡组，也可以自己组牌，组牌界面会帮你看这副牌缺什么。
- 闯关：七个场地 35 关，每个场地最后是首领，打赢获得首领牌。
- 全程没有随机（除了开局洗牌）：每一步会发生什么，选牌时就画给你看。

## 已知的不足

- 还没有新手引导，规则要点写在试玩页上。
- 手机横屏的适配正在做，目前在电脑上体验最好。
- 首领的专属动作、设置页还没做；声音没有细调。
- 闯关的难度只用电脑模拟校准过。

## 在自己电脑上运行

不需要安装依赖，也不需要构建。

```bash
python3 tools/serve.py 8770
```

然后打开 `http://localhost:8770/board.html`。

规则自检：

```bash
node tools/chess_check.mjs
```

## 目录

| 文件 | 内容 |
|---|---|
| `chess.js` | 规则核心和电脑的打法 |
| `chess-cards.js` | 全部卡牌 |
| `campaign.js` | 闯关的关卡数据和存档 |
| `board3d.js` | 场景和特效（three.js，全部用代码画） |
| `chess-ui.js`、`style.css`、`motion.css` | 界面和动效 |
| `audio.js`、`sound.js` | 声音 |
| `tools/` | 自检、平衡、打包、画图标的脚本 |
| `pages/` | 试玩和反馈页 |
